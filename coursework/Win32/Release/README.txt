Курсовая работа представлена исполняемым файлом и вспомогательными файлами данных. Для корректной работы приложения необходимо сохранить структуру файлов и директорий в неизменном виде.

Состав компонентов:

– coursework.exe — исполняемый файл приложения. Для запуска необходимо выполнить двойной щелчок левой кнопкой мыши по данному файлу.

– EnemySpawnsData.dat — типизированный файл, содержащий записи о расписании волн противников (идентификатор типа врага, временной интервал появления, количество противников в волне).

– textures\ — директория с графическими ресурсами: текстурами клеток поля (трава, дорога, база) и изображениями трёх типов турелей в формате BMP.
